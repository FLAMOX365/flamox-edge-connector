# Support

Use [GitHub issues](https://github.com/FLAMOX365/flamox-edge-connector/issues)
for reproducible defects, documentation gaps, and focused usage questions.
Search existing issues first and include the Edge Connector version, Node.js
version, operating system, deployment form, minimal reproduction, and redacted
logs where relevant.

Community support is provided on a best-effort basis and does not create a
service-level commitment. Contractual FLAMOX365 support remains governed by the
applicable customer agreement.

Do not report credentials, private configuration, customer data, or suspected
vulnerabilities in a public issue. Follow the
[security policy](docs/SECURITY.md) for security-sensitive reports.
